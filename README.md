# 星級遊戲 QR 收集冊

麥當勞 1+1 星級遊戲（2026）的 QR Code 眾籌清單，非官方整理。

https://huangyouci.github.io/web-mcd-stargame-2026-github/

## 主要功能

- **QR Code**：所有收錄的 QR Code，點一下放大給另一支手機掃，或直接開啟網址。
- **兌換紀錄**：勾選已兌換，存在自己的瀏覽器；可匯出／匯入。
- **掃描**：用相機、照片或網址讀 QR Code，馬上知道是否已收錄、自己是否兌換過。
- **投稿**：沒收錄的 QR Code 透過 GitHub Issue 投稿，經管理者確認後收錄。
- **回報無法使用**：掃了沒效果的 QR Code 可以回報，網站會標示回報人數。
- **點位**：星級地圖上的全台點位，可依類型與縣市篩選。
